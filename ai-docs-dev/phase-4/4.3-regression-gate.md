# Phase 4.3: Automated Regression Gate & Final Colab Verification

## เป้าหมาย (Goal)
รวมทุกชุดทดสอบและ Smoke Benchmark เป็นคำสั่ง **Automated Regression Gate** คำสั่งเดียวที่รันได้ทั้งในเครื่องพัฒนา/CI (CPU Fast Gate) และบน Google Colab (Full GPU Gate) พร้อมออก **Final Verification Text Report**

---

## ไฟล์และโมดูลเป้าหมาย
- `scripts/run_gate.py` — Unified Gate Runner (`--mode fast` สำหรับ CPU/CI, `--mode full` สำหรับ Google Colab GPU)
- `tests/unit/` & `tests/migrate/` — ชุดทดสอบทั้งหมด
- `pipline-for-test/` — Smoke Benchmark Suite
- `.github/workflows/ci.yml` — *(optional)* CI workflow สำหรับ Fast Gate (`unit + cpu-safe migrate`)

---

## งานย่อยแบบละเอียด (Tasks)
- [ ] **Fast Gate (`python scripts/run_gate.py --mode fast`)**:
  - รัน Unit tests ทั้งหมด (รวม mock hardware matrix & kernel CPU guards)
  - รัน CPU-compatible Migrate tests (Script + Checkpoint + Config migration)
  - ออกรายงาน `report/HHMMSS_YYYYMMDD-phase-4-fast.txt`
- [ ] **Full Colab GPU Gate (`python scripts/run_gate.py --mode full`)**:
  - รัน `ptopt --doctor` + `--explain`
  - รัน Unit tests ทั้งหมด (รวม Triton Kernel forward/backward parity บน GPU จริง)
  - รัน Migrate tests ครบทั้ง 3 มิติบน GPU จริง
  - รัน Smoke Benchmark (`Baseline` vs `safe` vs `balanced` vs `aggressive`) ใน `pipline-for-test/`
  - ออก **Final Consolidated Text Report**: `report/HHMMSS_YYYYMMDD-phase-4.txt` พร้อม Verdict (`PASS` / `FAIL`) และ `Verification Status: PENDING_USER_REVIEW`
