   - ใน [`report/061553_20261118-phase-5.3.txt#L89`](../../report/061553_20261118-phase-5.3.txt#L89): `fp8_compile` ยังต้องทำ dynamic `x.abs().amax()` reduction อ่าน activation เต็ม tensor 2 รอบทุก `nn.Linear` และ [`apply_fp8_linear_eval_hooks`](../../src/passes/inference_opt.py#L297) ยังข้าม `nn.MultiheadAttention.in_proj_weight`
3. **Heuristics & Startup Polish (`channels_last`, `optimizer_fusion`, `dataloader_tune`, `cli`)**:

## 3. งานย่อย (Implementation Tasks)
- [ ] **1. Fused RoPE & Zero-Copy Row-Strided Triton Kernels + Guardrail #1**:
  - เพิ่ม `triton_rope(q, k, cos, sin)` (Forward + Backward) ใน `rope_or_swiglu.py` พร้อม ref fallback และ unit parity test
  - **Guardrail #1 (Strict Semantic Matching สำหรับ `SwiGLU` & `RoPE`)**:
    - `SwiGLUMLP` patcher ใน `registry.py`: จับได้ทั้ง `(w_gate, w_up, w_down)` และ `(gate_proj, up_proj, down_proj)` **แต่ต้องเช็ก `act_fn` ว่าเป็น `nn.SiLU` (หรือชื่อ class มี `"swiglu"`) และไม่มี submodule แปลกปลอม (เช่น `Dropout` / norm เสริม)** เพื่อไม่ให้เผลอ patch **GeGLU (`GELU` ใน Gemma/T5)** หรือ `ReGLU` จนคณิตศาสตร์โมเดลผิด!
    - `RoPE` auto-patcher: ห้ามเดาจากชื่อ class อย่างเดียว — auto-patch เฉพาะ signature/layout ที่ตรวจ `q/k/cos/sin` shape, dtype, และสูตร rotation (half-rotate vs interleaved) ชัดเจน หรือจำกัดเป็น verified pattern + fallback ทันที
  - แก้ `triton_rmsnorm`, `triton_layernorm`, `triton_cross_entropy`, `triton_swiglu` ให้รับ 2D view ที่มี `stride(-1) == 1` โดยส่ง `stride_row` เข้า Triton **ไม่บังคับ `.contiguous()` copy** (ลด peak VRAM บน causal LM slice `logits[:, :-1]`)
  - ใน `cross_entropy.py`: คำนวณ `valid_count` ใน Triton forward หรือ single reduction ลด kernel launches; ใน `rmsnorm.py`/`layernorm.py`: pack 4–8 rows/CTA เมื่อ `N <= 1024`
- [ ] **2. FP8 Inference Refinements (`src/passes/inference_opt.py`)**:
  - แก้ `has_large_m` (บรรทัด 547) ให้รองรับ 2D integer/token inputs `(B, S)` ด้วย (`B * S >= 512`) เพื่อ prewarm weight caches ก่อน compile ใน LLM eval
  - เพิ่ม opt-in **Calibrated Static/EMA Activation Scale** (`PTOPT_FP8_STATIC_SCALE=1`): calibrate `x_scale` ใน 1–2 warmup steps แรก (พร้อม EMA / safety headroom `1.05x–1.1x` หรือ outlier guard ไม่ให้ clip หนักเมื่อ distribution เปลี่ยน) แล้วสลับใช้ static scale (`x * inv_scale` ใน 1 pass โดยไม่ต้องลด `amax()` 2 รอบทุก Linear)
  - ตรวจ/รองรับ FP8 QKV projection ใน `nn.MultiheadAttention` เมื่อ `in_proj_weight` มีขนาดผ่าน gate โดยไม่กระทบ `state_dict()`
- [ ] **3. Pipeline, Heuristic & Startup Polish + Guardrail #5**:
  - **`channels_last.py`**: ปรับ auto gate ให้เช็กทั้ง `H * W >= 16384` **หรือ** `(B * C >= 4096 and H * W >= 4096)` และเพิ่ม `channels_last_3d` สำหรับ `Conv3d`
  - **`optimizer_fusion.py` + Guardrail #5a (`capturable=True`)**: เพิ่ม `foreach=True` สำหรับ `RMSprop`, `Adagrad`, `NAdam`, `RAdam`; เปิด `capturable=True` **เฉพาะ opt-in (`PTOPT_OPTIM_CAPTURABLE=1`)** พร้อม normalize `state[p]["step"]` ใน `checkpoint_compat.py` เพื่อไม่ให้ checkpoint cross-load ระหว่าง CPU↔CUDA พัง
  - **`dataloader_tune.py` & `runtime_flags.py`**: Cache CUDA prefetch stream ต่อ device ใน `_AsyncCudaPrefetchIter` และปิด `cudnn_benchmark` อัตโนมัติหาก `auto_compile` ตรวจพบ dynamic shape บน Conv2d model
  - **`detect/fingerprint.py` / `cli/main.py` + Guardrail #5b (Cache Freshness)**: เพิ่ม disk cache เฉพาะ static GPU/host fields โดยผูก key กับ `(hostname, CUDA_VISIBLE_DEVICES, torch_version, triton_version, driver_version)` และ **ต้อง probe `/dev/shm` สดทุกครั้งเสมอ (ห้าม cache `/dev/shm`)** พร้อม `PTOPT_NO_FP_CACHE=1` เพื่อ bypass
