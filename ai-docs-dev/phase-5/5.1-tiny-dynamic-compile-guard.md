## 3. งานย่อย (Implementation Tasks)
- [ ] **เพิ่ม Metric ประเมินขนาดโมเดล/ภาระงาน (`_estimate_module_work(mod_self, args, kwargs)`)**:
  - นับจำนวน parameters ทั้งหมด (`total_params`) และขนาด activation element สูงสุดจาก input tensors
  - ตั้งเกณฑ์ `MIN_DYNAMIC_COMPILE_PARAMS` (เช่น `< 250_000` parameters และ tiny input elements) — รองรับ override via `PTOPT_COMPILE_DYNAMIC_MIN_PARAMS` หรือ `PTOPT_COMPILE_DYNAMIC_SMALL=1`
- [ ] **Safe Eager Revert เมื่อโมเดลเล็ก + Shape เปลี่ยน**:
  - ใน `_compile_mod_call` ของ `auto_compile.py` เมื่อ detect ว่า shape signature เปลี่ยนเป็นครั้งที่ 2 (`len(seen_shapes) > 1`):
    - **โมเดลใหญ่ (>= threshold)**: คงพฤติกรรมเดิม — recompile 1 ครั้งด้วย `dynamic=True` (`APPLIED`)
    - **โมเดลเล็ก (< threshold)**: ถอด `_compiled_call_impl = None`, ตั้ง `_ptopt_compile_ineligible = True`, และบันทึก event `FALLBACK` ชัดเจน (`"Small dynamic-shape module reverted to eager for profitability"`)
- [ ] *(Optional Check)* **Compile-Time Guard for Zero-Benefit Dynamic Overhead**:
  - ตรวจว่าถ้า `mod_self` ถูก compile กลับมาเป็น Eager แล้ว `torch.cuda` / `state_dict()` ยังคง clean 100%
