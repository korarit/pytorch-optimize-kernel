# Phase 2.4: Baseline Migrate Test Suite (Script & Checkpoint Cross-Load)

## เป้าหมาย (Goal)
สร้างชุด **Migrate Tests** ตั้งต้นใน `tests/migrate/` เพื่อพิสูจน์ว่าการนำโค้ด PyTorch เดิมมารันผ่าน `ptopt` ไม่ทำให้สคริปต์พัง และ checkpoint (`state_dict`) สามารถย้ายข้ามไปมาระหว่าง Baseline ↔ Wrapped ได้สมบูรณ์

---

## ไฟล์และโมดูลเป้าหมาย
- `src/hooks/checkpoint_compat.py` — Helper / hook จัดการ `state_dict()` และ `load_state_dict()` ให้ key สะอาด (เช่น Strip/Normalize `_orig_mod.` prefix)
- `tests/migrate/test_script_migration.py` — รัน unmodified workloads + edge cases ผ่าน `ptopt`
- `tests/migrate/test_checkpoint_compat.py` — ทดสอบ Save/Load checkpoint ข้าม Baseline ↔ Wrapped
- `scripts/verify_phase2.py` — รัน Unit + Migrate + Smoke Benchmark ปิดท้าย Phase 2 และออก report

---

## งานย่อยแบบละเอียด (Tasks)
- [ ] **Test Group 1: Unmodified Script Migration (`test_script_migration.py`)**:
  - รัน `cnn_vision.py`, `transformer_lm.py`, `deep_mlp.py`, `infer_runner.py`, และ `edge_cases.py` ผ่าน `ptopt --profile safe` โดยไม่แก้ไฟล์ workload
  - ตรวจ exit code == 0, ไม่มี unhandled exception, loss parity ผ่านเกณฑ์ Phase 0
- [ ] **Test Group 2: Checkpoint Cross-Compatibility (`test_checkpoint_compat.py`)**:
  - เคส A: Baseline train 5 steps → `torch.save` (`model.state_dict()` + `optimizer.state_dict()`) → Wrapped โหลดไปเทรนต่อ 5 steps → ต้องโหลดผ่านและ loss ต่อเนื่อง (เทียบกับ Baseline 10 steps)
  - เคส B: Wrapped train 5 steps → `torch.save` → **PyTorch ปกติ (Unwrapped)** โหลดไปเทรน/inference ต่อ → ต้องโหลดผ่านทันทีโดย keys ตรงเป๊ะไม่มี `_orig_mod.` หรือ wrapper prefix ติดมา
  - เคส C: ตรวจค่า weight tensors หลังโหลดกลับว่า dtype และ shape ตรงตามเดิม
