# Phase 2.3: Non-Invasive Telemetry & A/B Benchmark Harness

## เป้าหมาย (Goal)
สร้างระบบเก็บ Telemetry แบบไม่ต้องแก้โค้ด user และสร้าง A/B Benchmark Runner (`bench.py`) ที่แยกวัด Baseline vs Wrapped อย่างแม่นยำตามกฎการวัด GPU พร้อมออก **Detailed Text Report** ใน `report/`

---

## ไฟล์และโมดูลเป้าหมาย
- `src/hooks/telemetry_hook.py` — Non-invasive telemetry hook (เปิดเมื่อตั้ง `PTOPT_TELEMETRY_OUT=<path.json>`)
- `pipline-for-test/telemetry.py` — Schema & statistics calculator (median, p95, min, max, std, speedup, VRAM delta)
- `pipline-for-test/bench.py` — Subprocess A/B orchestrator (Cold vs Warm, multi-profile)
- `pipline-for-test/report.py` — Detailed Text Report formatter (`.txt` + stdout) และ JSON/CSV exporter
- `tests/unit/test_telemetry_and_bench.py` — Unit tests สำหรับสถิติ, JSON schema และ text table formatting

---

## งานย่อยแบบละเอียด (Tasks)
- [ ] **Non-Invasive Telemetry Hook**:
  - จับเวลาต่อ step รอบ `Optimizer.step` (หรือ `Module.forward` ในโหมด inference) โดยใช้ `torch.cuda.synchronize()` / `torch.cuda.Event(enable_timing=True)` เมื่อรันบน GPU
  - แยกเก็บ `warmup_steps` (เช่น 20% แรกหรือ N steps แรก) ออกจาก `steady_steps`
  - เก็บ `peak_allocated_mb`, `peak_reserved_mb`, `end_to_end_sec`, `step_losses` (capture scalar loss จาก backward/stdout parser หรือ hook) และ `fallback_events`
- [ ] **Subprocess A/B Runner (`bench.py`)**:
  - รัน Baseline และ Wrapped ใน subprocess แยกขาดกัน (ป้องกัน CUDA allocator/compile cache ปนกัน)
  - รองรับโหมดล้าง `TORCHINDUCTOR_CACHE_DIR` เพื่อวัด **Cold Run** และรันซ้ำเพื่อวัด **Warm Run**
  - รันซ้ำ N trials ได้และตรวจ Parity ระหว่าง Baseline loss กับ Wrapped loss อัตโนมัติ
- [ ] **Detailed Text Report (`report.py`)**:
  - สร้างไฟล์ `report/HHMMSS_YYYYMMDD-<name>.txt`
  - แสดง: Header, Hardware Fingerprint, Config Profile Summary, ตารางเปรียบเทียบ (Baseline vs Wrapped: Steady Step ms, P95 ms, Speedup x, End-to-End s, Peak VRAM MB, Max Loss Diff, Status), และรายละเอียด Fallback/Errors

---

## Unit Tests (`tests/unit/test_telemetry_and_bench.py`)
- [ ] ทดสอบการคำนวณ percentile (median, p95), speedup ratio, memory delta และ parity pass/fail threshold
- [ ] ทดสอบ `telemetry_hook.py` กับ dummy training loop (CPU) → ต้องได้ JSON ที่มี step times, losses, memory ครบ
- [ ] ทดสอบ `report.py` สร้าง `.txt` ในรูปแบบตารางอ่านง่ายและไม่มี crash เมื่อบาง workload fail หรือ skip
