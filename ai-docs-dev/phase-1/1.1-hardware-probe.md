# Phase 1.1: Hardware & Runtime Probe + Text Report Foundation

## เป้าหมาย (Goal)
สร้างโมดูลตรวจจับสเปก GPU และเครื่อง (Host) ที่ทำงานได้ทั้งบน Google Colab (T4, L4, A100, CPU), Linux ทั่วไป, และโหมดไม่มี GPU พร้อมวาง **Shared Text Report Utility** ที่ใช้รูปแบบ `report/HHMMSS_YYYYMMDD-<name>.txt`

---

## ไฟล์และโมดูลเป้าหมาย
- `src/detect/__init__.py`
- `src/detect/gpu_probe.py` — ตรวจ GPU backend, compute capability, VRAM, feature support
- `src/detect/host_probe.py` — ตรวจ CPU arch, physical/logical cores, RAM, `/dev/shm`, Python/PyTorch/Triton/allocator
- `src/detect/fingerprint.py` — `HardwareFingerprint` dataclass + JSON serializer
- `src/common/text_report.py` — ตัวช่วยสร้างไฟล์ `report/HHMMSS_YYYYMMDD-<name>.txt` + พิมพ์ออก stdout
- `scripts/verify_phase1_1.py` — script รัน probe + unit test แล้วออก report

---

## งานย่อยแบบละเอียด (Tasks)
- [ ] **GPU Probe**:
  - ตรวจ backend: `cuda` / `rocm` (`torch.version.hip`) / `mps` / `cpu`
  - ตรวจ device properties: `device_index`, `name`, `compute_capability` (`major`, `minor`, `sm_int` เช่น `75`, `80`, `89`, `90`), `total_vram_mb`, `sm_count`
  - ตรวจ capability flags: `bf16_supported`, `tf32_supported` (`sm >= 80`), `fp8_supported` (`sm >= 89`), `flash_sdp_supported`
  - รองรับ Multi-GPU (อ่าน `CUDA_VISIBLE_DEVICES` / target device index) และ Safe Fallback เมื่อไม่มี GPU หรือ driver error
- [ ] **Host / Machine Probe**:
  - ตรวจ `os_name`, `os_release`, `cpu_arch` (`x86_64` / `aarch64` / `arm64`), `is_colab` (detect Google Colab runtime)
  - ตรวจ `physical_cores` vs `logical_cores`, `total_ram_mb`, `shm_size_mb` (อ่าน `/dev/shm` ผ่าน `os.statvfs`)
  - ตรวจ Software Stack: `python_version`, `torch_version`, `cuda_version`, `triton_version`, `jemalloc_path`, `tcmalloc_path`
- [ ] **Text Report Utility**:
  - สร้างโฟลเดอร์ `report/` อัตโนมัติถ้ายังไม่มี
  - ตั้งชื่อไฟล์ตาม format `HHMMSS_YYYYMMDD-<name>.txt` (local time)
  - เขียนทั้งลงไฟล์และแสดงผลบน Colab cell ได้สวยงามอ่านง่าย

---

## Unit Tests (`tests/unit/test_detect.py`)
- [ ] Mock `torch.cuda` และ `/dev/shm` สำหรับเครื่องจำลอง 7 แบบ:
  1. Google Colab T4 (`sm_75`, 15GB VRAM, `/dev/shm` ต่ำ)
  2. Google Colab L4 (`sm_89`, 22.5GB VRAM)
  3. Google Colab A100 (`sm_80`, 40GB/80GB VRAM)
  4. Hopper H100 (`sm_90`, 80GB VRAM, FP8 ready)
  5. Apple Silicon (`mps`, `arm64`)
  6. CPU-only (`x86_64` vs `aarch64`)
  7. Container `/dev/shm` เล็ก (`512 MB`) หรือ `torch.cuda` raise RuntimeError
- [ ] ทดสอบ `HardwareFingerprint.to_dict()` / `to_json()` round-trip
