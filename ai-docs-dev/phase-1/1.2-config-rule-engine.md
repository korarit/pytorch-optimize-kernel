# Phase 1.2: Config Schema v1, Profiles & Layered Rule Engine

## เป้าหมาย (Goal)
สร้างระบบ **Config Schema v1** และ **Layered Rule Merge Engine** ที่เลือก/ปรับแต่งค่า optimization ตาม `HardwareFingerprint` จาก Phase 1.1 พร้อมบันทึก **Resolution Trace** ว่า rule ไหนเปลี่ยนค่าอะไร

---

## ไฟล์และโมดูลเป้าหมาย
- `src/config/__init__.py`
- `src/config/schema.py` — `OptimizeConfig` dataclasses + Schema v1 validator (`schema_version = 1`)
- `src/config/rules_builtin.py` (หรือ `rules.yaml`) — นิยาม rules แยกตาม layer
- `src/config/resolver.py` — `ConfigResolver` ทำ layered merge + เก็บ trace + CLI/ENV override
- `scripts/verify_phase1_2.py` — script ทดสอบ resolution matrix + unit tests แล้วสร้าง report

---

## งานย่อยแบบละเอียด (Tasks)
- [x] **Config Schema v1 (`OptimizeConfig`)**:
  - หมวดหมู่ครบตาม Phase 0 Spec (`runtime`, `amp`, `compile`, `optimizer`, `attention`, `dataloader`, `inference`, `kernels`)
  - Cross-field validation: เช่น ถ้า `amp.dtype == "bf16"` และ `amp.enabled == True` ต้องเตือน/ป้องกัน `grad_scaler = True`; ถ้า `backend == "cpu"` ต้องไม่เปิด CUDA flags
- [x] **Layered Resolution Precedence (เรียงจากต่ำไปสูง)**:
  1. `base` (safe defaults)
  2. `host_arch` rules (`linux_x86_64`, `linux_aarch64`, `darwin_mps`, `low_shm_guard` เมื่อ `shm_size_mb < 2048`, `colab_runtime`)
  3. `gpu_arch` rules (`cuda_volta_turing_sm70_79`, `cuda_ampere_sm80_86`, `cuda_ada_sm89`, `cuda_hopper_sm90_plus`, `rocm`, `mps`, `cpu_only`)
  4. `vram_tier` rules (`vram_lt_12gb`, `vram_12_24gb`, `vram_ge_40gb`)
  5. `user_profile` (`safe`, `balanced`, `aggressive`)
  6. `explicit_overrides` (CLI flags / `PTOPT_*` environment variables — ชนะทุกชั้นเสมอ)
- [x] **Resolution Trace**:
  - ทุก field ที่ถูกเปลี่ยน ต้องบันทึก `(field_path, old_val, new_val, rule_name, reason)` เพื่อนำไปพิมพ์ใน `--explain` และ Text Report

## Unit Tests (`tests/unit/test_config_resolver.py`)
- [x] ทดสอบ Mock Matrix บนทุก profile (`safe`, `balanced`, `aggressive`):
  - T4 (`sm_75`) + `balanced` → `tf32=False`, `amp.dtype="fp16"`, `amp.grad_scaler=True`, `attention.flash_sdp=False`
  - A100 (`sm_80`) + `balanced` → `tf32=True`, `amp.dtype="bf16"`, `amp.grad_scaler=False`, `attention.flash_sdp=True`
  - L4 (`sm_89`, 22.5GB) + `aggressive` → เปิด capability สำหรับ custom kernels / max-autotune
  - Low `/dev/shm` (`< 2048 MB`) → `dataloader.auto_tune=False` หรือจำกัด `num_workers`
  - CPU-only → ปิด `amp.enabled` (CUDA), `optimizer.fused=False`, ตั้ง `omp_threads` ตาม physical cores
- [x] ทดสอบ Precedence & Overrides (`PTOPT_PROFILE`, `PTOPT_COMPILE=0`, `--no-amp`) ชนะ rule ชั้นล่างทั้งหมด
- [x] ทดสอบ Validation Errors (unknown key, invalid dtype, invalid profile name)
