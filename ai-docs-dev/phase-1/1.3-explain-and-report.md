# Phase 1.3: `--explain` CLI & Phase 1 Consolidated Report

## เป้าหมาย (Goal)
สร้างคำสั่งตรวจสอบ config (`--explain` / `--show-config`) และ script ปิดท้าย Phase 1 ที่สรุปทั้ง Hardware Probe + Config Rule Trace + Unit Test Suite ทั้งหมดลงใน Text Report เดียว

---

## ไฟล์และโมดูลเป้าหมาย
- `src/cli/explain.py` — Formatter สำหรับแสดง Hardware Fingerprint, Matched Rules, Trace, และ Final Config
- `scripts/verify_phase1.py` — Consolidated Phase 1 verification & Text Report generator
- `tests/unit/test_explain_cli.py` — Unit tests สำหรับ output formatting และ JSON/text snapshot
