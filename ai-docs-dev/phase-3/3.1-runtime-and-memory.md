# Phase 3.1: Runtime Flags, Memory Allocator & `channels_last`

## เป้าหมาย (Goal)
ทดลองและปรับจูน Optimization ที่ความเสี่ยงต่ำที่สุด (Low-risk Runtime & Memory Tuning) ที่สามารถเปิดใน `safe` / `balanced` profile ได้โดยไม่แตะ training loop logic

---

## ไฟล์และโมดูลเป้าหมาย
- `src/passes/runtime_flags.py` — TF32, `float32_matmul_precision`, `cudnn.benchmark`, SDPA backend flags
- `src/passes/memory_allocator.py` — `PYTORCH_CUDA_ALLOC_CONF`, `jemalloc`/`tcmalloc` preload, CPU thread tuning (`OMP_NUM_THREADS`, `MKL_NUM_THREADS`)
- `src/passes/channels_last.py` — Safe `memory_format=torch.channels_last` (เฉพาะโมเดล Conv2d/4D tensor ที่รองรับ)
- `tests/unit/test_pass_runtime_memory.py` — Unit tests สำหรับ flag application และ arch guards
- `scripts/exp_phase3_1.py` — รันทดลอง A/B บน Colab และสร้าง Detailed Text Report

---

## งานทดลองแบบละเอียด (Experiment Tasks)
- [ ] **CUDA Math & Attention Flags**:
  - ทดลอง `torch.set_float32_matmul_precision("high")`, `allow_tf32`, `cudnn.benchmark` (เฉพาะ `sm >= 80` สำหรับ TF32)
  - ทดลองเปิด `enable_flash_sdp(True)` / `enable_mem_efficient_sdp(True)` ตาม GPU capability (T4 vs L4 vs A100)
- [ ] **Memory Allocator & CPU Host**:
  - ทดลอง `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True` (วัดผล Peak Reserved VRAM & OOM resistance)
  - ทดลอง `OMP_NUM_THREADS` / `MKL_NUM_THREADS` และ `LD_PRELOAD` `libjemalloc` (ถ้ามีในเครื่อง Colab)
- [ ] **Channels-Last Experiment (CNN)**:
  - ทดลองสลับ 4D weights/inputs เป็น `channels_last` เฉพาะโมเดลที่มี `Conv2d` และทดลองผลข้างเคียงกับ checkpoint `state_dict` (ต้องกลับมาเป็น contiguous/standard ได้ถ้าจำเป็น)
