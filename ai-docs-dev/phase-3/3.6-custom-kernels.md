# Phase 3.6: Custom Kernels (Triton / CUDA), Capability Gate & Phase 3 Consolidation

## เป้าหมาย (Goal)
พัฒนา **Custom Triton / CUDA Kernels** สำหรับ ops ที่เป็นคอขวด เสียบเข้า PyTorch อัตโนมัติผ่าน **Capability Gate** (fallback กลับไปใช้ PyTorch native op ได้ทันทีถ้าการ์ดไม่รองรับ) พร้อมสรุปผลการทดลองทั้งหมดใน Phase 3 เข้า Profile หลัก

---

## ไฟล์และโมดูลเป้าหมาย
- `src/kernels/__init__.py`
- `src/kernels/registry.py` — `KernelSpec` (`min_sm`, `supported_dtypes`, `triton_required`, `fallback_on_error`) & Auto-Patcher
- `src/kernels/rmsnorm.py` — Custom Triton RMSNorm (Forward + Backward)
- `src/kernels/layernorm.py` — Custom Triton Fused LayerNorm (ทดลองเทียบกับ PyTorch native / compile)
- `src/kernels/cross_entropy.py` — Custom Triton Fused CrossEntropy (ลด peak memory ของ logits ที่ใหญ่มาก)
- `src/kernels/rope_or_swiglu.py` — (เพิ่มเติมตามผล profiling ของ `transformer_lm.py`)
- `tests/unit/test_kernels_parity.py` — Forward + Backward gradient tests เทียบ PyTorch reference
- `scripts/exp_phase3_6.py` — Kernel Micro-benchmarks + End-to-End `transformer_lm.py` A/B
- `scripts/verify_phase3.py` — Full Phase 3 Benchmark Matrix (`Baseline` vs `safe` vs `balanced` vs `aggressive`)

---

## งานทดลองแบบละเอียด (Experiment Tasks)
- [ ] **Kernel Registry & Capability Gate**:
  - ตรวจ `triton_available`, `sm_int >= kernel.min_sm`, `dtype in kernel.supported_dtypes` ก่อน patch
  - ถ้าไม่ผ่านเงื่อนไข (เช่น รันบน CPU หรือ GPU เก่าที่ kernel ไม่รองรับ) → ข้าม kernel นั้นและบันทึกเข้า `FallbackRegistry`
- [ ] **Custom Kernels Development & Micro-Benchmark**:
  - เขียน Kernel ทีละตัว (เริ่มจาก `RMSNorm` → `CrossEntropy` → `SwiGLU` / `RoPE`)
  - วัด Micro-benchmark (`ms`, `GB/s`) เทียบกับ: 1) PyTorch Eager และ 2) `torch.compile` (เพื่อพิสูจน์ว่า custom kernel ชนะจริง หรืออันไหนให้ `torch.compile` ทำแทนจะดีกว่า!)
- [ ] **End-to-End Integration & Consolidation**:
  - นำเฉพาะ pass/kernel ที่ผ่าน **Promotion Gate** จาก Phase 3.1–3.6 มาจัดวางลง `safe` / `balanced` / `aggressive` profiles ใน `src/config/rules_builtin.py`

## Unit & Migrate Tests
- [ ] **Kernel Unit Tests (`test_kernels_parity.py`)**:
  - ทดสอบ Forward + Backward (`torch.autograd.gradcheck` / `allclose` เทียบ fp64/fp32 reference)
  - ทดสอบ edge shapes: non-power-of-2 hidden dim (เช่น `384`, `768`, `1025`), batch=1, seq_len=1, `fp32` / `fp16` / `bf16`

- [ ] **Migrate Tests**:
