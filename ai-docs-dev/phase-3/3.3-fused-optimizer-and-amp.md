# Phase 3.3: Optimizer Fusion & Safe Auto-AMP

## เป้าหมาย (Goal)
เร่ง compute และลด VRAM ระหว่างเทรนด้วยการฉีด `fused=True` / `foreach=True` เข้า Optimizer และเปิด **Auto Mixed Precision (AMP)** (`bf16` บน `sm >= 80` หรือ `fp16 + GradScaler` บน `sm < 80` อย่าง Colab T4) แบบไม่ซ้อนทับกับโค้ดเดิมของผู้ใช้

---

## ไฟล์และโมดูลเป้าหมาย
- `src/passes/optimizer_fusion.py` — Hook `Adam`, `AdamW`, `SGD` เพื่อเปิด `fused=True` / `foreach=True`
- `src/passes/auto_amp.py` — Non-invasive AMP context + `GradScaler` management + pre-existing AMP detector
- `tests/unit/test_pass_optimizer_amp.py` — Unit tests สำหรับ fusion eligibility, double-AMP prevention และ NaN guard
- `scripts/exp_phase3_3.py` — ทดลอง A/B บน `transformer_lm.py`, `deep_mlp.py`, `cnn_vision.py`, `edge_cases.py`

---

## งานทดลองแบบละเอียด (Experiment Tasks)
- [ ] **Optimizer Fusion**:
  - ตรวจสอบ parameter devices (CUDA เท่านั้น), dtype และเวอร์ชัน PyTorch ก่อนฉีด `fused=True` (ถ้าไม่รองรับให้ fallback ไป `foreach=True` หรือค่าเดิม)
  - วัด speedup เฉพาะจุดบน `deep_mlp.py` (optimizer-overhead bound)
- [ ] **Safe Auto-AMP**:
  - เลือก `bf16` (ไม่ต้องใช้ `GradScaler`) บน A100/L4 (`sm >= 80`), เลือก `fp16 + GradScaler` บน T4 (`sm_75`)
  - **Pre-existing AMP Detection**: ตรวจจับ `torch.is_autocast_enabled('cuda')` ระหว่าง `forward` และตรวจจับว่า user เรียก `GradScaler.step()` อยู่แล้วหรือไม่ → ถ้ามีอยู่แล้ว **ห้ามซ้อนทับเด็ดขาด**
  - **GradScaler Injection (สำหรับ `fp16`)**: ครอบ `loss.backward()` และ `optimizer.step()` / `optimizer.zero_grad()` อย่างปลอดภัย พร้อมรองรับ gradient clipping (`unscale_`) ถ้าจำเป็น
  - **Stability Watchdog**: ตรวจหา `NaN`/`Inf` ใน loss → ถ้าพบให้แจ้งเตือนและมี option fallback กลับ `fp32`
